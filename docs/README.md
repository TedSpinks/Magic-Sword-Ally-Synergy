# Research and history

Working notes from the development of the patch. They record what was found in the original game and why things were
built the way they are; addresses are SNES LoROM (`bank:address`). Some sections describe earlier versions: the
development history says what changed when.

| File | Contents |
|---|---|

| `PERK_DECISIONS.md` | The ally perks: decisions, findings and implementation notes |
| `DOOR_CONTENTS.md` | Cell doors on every floor, what each contents id does, and the original game's door shuffle |
| `HIDDEN_DOORS.md` | The six hidden warp doors and how they trigger |
| `SCROLL_DROPS.md` | What the Scroll actually does to enemy drops |
| `PAUSE_LOG_NOTES.md` | The pause-screen Thief's Log: memory the game never touches, backups, checks |
| `GRAPHICS_FORMAT.md` | The game's sprite graphics format and how the hack's icons plug into it |
| `MESSAGES_BY_FLOOR.md` | The between-level messages, floor by floor |
| `FASTROM_STAIRS_NOTES.md` | A FastROM timing note |
