# Changelog

## 1.0.2
**Recommended update for everyone on 1.0.0 or 1.0.1.** Fixes a freeze when pressing START during the gameplay demo (the attract loop, after the character screens). Nothing else changes. Saved runs from earlier versions work as they are.

## 1.0.1
**Recommended update for everyone on 1.0.0.** Fixes a possible freeze when choosing RESUME on the slot screen, most likely right after powering on. It depends on what the console's memory holds at power-on, so it appeared on accurate emulators (bsnes) and probably can on real hardware, but not on Snes9x. Nothing else changes.

## 1.0.0
First public release of Magic Sword: Ally Synergy. See the [README](README.md) for everything it changes compared with the original game.
